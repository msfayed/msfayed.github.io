Base64 Encoder & Decoder

Convert text to Base64 or decode Base64 back to text. Everything runs locally, even offline. Base64 is an encoding, not encryption.

When encoding, this converts input text into bytes. When decoding, this interprets the decoded bytes as text. UTF-8 supports Arabic and emoji. Windows Arabic uses Windows-1256 and rejects unsupported characters. UTF-16 uses the selected byte order without adding or removing a byte-order mark.

Enter the text you want to encode.
